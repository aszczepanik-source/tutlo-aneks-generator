# Publikacja frontendu

## Konfiguracja lokalna

Uruchom `npm run check`. Aplikacja nie wymaga adresu ani konfiguracji backendu;
analizuje PDF i generuje DOCX lokalnie w przeglądarce.

## GitHub Pages

1. Włącz GitHub Pages ze źródłem **GitHub Actions**.
2. Push do `main` uruchomi testy, zbuduje wydanie i opublikuje frontend.

## Test wydania

Po publikacji użyj wyłącznie danych syntetycznych. Sprawdź klasyfikację umowy,
generowanie aneksu i pobranie lokalnego pliku DOCX.
