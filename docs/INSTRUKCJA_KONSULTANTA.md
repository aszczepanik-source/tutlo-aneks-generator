# Tutlo Annex Generator 1.0.1 — instrukcja konsultanta

1. Pobierz `tutlo-aneks-generator-1.0.1.zip` z firmowego źródła.
2. Rozpakuj ZIP do nowego folderu (nie uruchamiaj aplikacji wewnątrz ZIP).
3. Otwórz `index.html` w Chrome. Nie instaluj Node.js i nie uruchamiaj serwera.

## Aktualizacja

Zamknij aplikację, usuń cały stary folder, rozpakuj nową wersję i ponownie otwórz `index.html`. Nie kopiuj nowych plików na starą wersję.

PDF jest analizowany lokalnie. Dane umowy nie są wysyłane do backendu, a plik DOCX jest generowany lokalnie w przeglądarce.
